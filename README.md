# CWA RR/LA Toolkit Hub

Rapid Response & Layoff Aversion Toolkit Hub for the California Workforce Association.

A self-contained single-page web app that organizes rapid response and layoff
aversion strategies, tools, and templates for California workforce boards.

## Deploy

The site is a single static `index.html` with a Netlify SPA redirect (`_redirects`).

- **Publish directory:** repository root (`netlify.toml`)
- **Live site:** deployed via Netlify (CWA team)

## Local preview

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Source

Base code maintained by the CWA team. Built from the "RR-LA Toolkit Hub"
